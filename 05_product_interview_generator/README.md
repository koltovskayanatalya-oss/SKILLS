# Product Interview Generator — навыки ИИ для CustDev-интервью (AJTBD)

Два навыка (skills) для ИИ-агента (Antigravity и совместимых), которые по диалогу собирают **гайд CustDev-интервью по методологии AJTBD (Advanced Jobs To Be Done)** и **обязательно проверяют его на соответствие методологии**.

| Навык | Что делает |
|---|---|
| [`custdev-guide-generator`](custdev-guide-generator/SKILL.md) | Диалоговый: задаёт по одному вопросу (B2B/B2C, бизнес-задача, гипотезы, тип работ, длительность, оффер и др.), затем собирает гайд с таймингом, вопросами и шаблонами фиксации |
| [`custdev-guide-validator`](custdev-guide-validator/SKILL.md) | Финальная проверка: чек-лист ~35 пунктов (PASS/FAIL), автоисправление, отчёт; вызывается генератором обязательно |

## Возможности
- B2C (частотные и последовательные работы) и B2B (личные работы ЛПР, роли в сделке, бюджет, рекомендатели)
- Типы исследований: среди своих клиентов, среди клиентов конкурентов, поиск работы и сегмента с нуля
- Разнесение гипотез пользователя по блокам гайда («где проверяется») и анти-наведение: открытый вопрос → гипотеза → контроль «не навёл ли я»
- Вопросы блока изучения работы — **дословно из банка вопросов**, подстановка только плейсхолдеров
- Подгонка тайминга (стандарт B2C 60 мин: 3+10+47; B2B ~70 мин)
- Опциональные блоки: решенческое интервью, switch- и проблемное интервью, работы ниже уровнем
- Финальный отчёт валидатора вставляется в гайд

## Установка
Скопируйте обе папки навыков (`custdev-guide-generator`, `custdev-guide-validator`) **рядом друг с другом** в каталог навыков:
- в проект: `<проект>/.agents/skills/`
- глобально: каталог навыков пользователя вашего агента

Навыки ссылаются друг на друга по относительным путям (`../custdev-guide-validator/`, `../custdev-guide-generator/references/`), поэтому держите их в одной родительской папке.

## Использование
1. Напишите агенту: «Запусти `custdev-guide-generator`: нужен гайд CustDev-интервью» (можно сразу приложить вводные: описание продукта, гипотезы, задачу).
2. Отвечайте на вопросы по одному. Команды в любой момент: «покажи что собрано», «вернись к вопросу N», «пропусти», «сгенерируй сейчас» (с явными допущениями).
3. Подтвердите сводку — агент соберёт гайд, сохранит в файл и запустит валидатор.
4. Получите гайд + отчёт проверки + список допущений.

## Пример
[`examples/yandex-maps-weather-guide.md`](examples/yandex-maps-weather-guide.md) — гайд для концепции «Погодный контекст маршрута» в Яндекс.Картах: 4 продуктовые гипотезы, B2C, частотные работы, 77 мин, решенческий блок на прототипе, отчёт валидатора внутри.

## Ограничения
- Интервью даёт работы, контексты, триггеры, критерии, барьеры и реакцию на оффер; **не подтверждает метрики** (конверсия, DAU, retention) — для этого A/B и аналитика.
- Гайд — заготовка для интервьюера; квалифицирующие вопросы и решенческий блок нужно адаптировать под конкретный оффер.
- Качество результата зависит от точности вводных; недостающие данные агент фиксирует как допущения.

## Источники методологии и права
Навыки составлены на основе материалов по AJTBD: гайды AJTBD-интервью v3.3 (B2C, B2B), лекции «Как проводить AJTBD-интервью», «Главная идея AJTBD», конспект курса Ивана Замесина. Банк вопросов воспроизводит формулировки этих материалов.
